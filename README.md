# dasc-nonexchangeable-streaming

> **Correction notice (30 October 2026).** The manuscript in this repository reports that DASC narrows prediction intervals by about 28% on the household electricity data and about 42% on the hourly weather data. Those figures do not hold. In the experiments behind them, DASC used the previous observation as its point forecast, while the comparison methods used the observation 24 hours earlier, so the intervals were not comparable. When every method is built on the same point forecast and tuned in the same way, DASC does not give narrower intervals than adaptive conformal inference: the two have near-nominal coverage and about the same width on electricity, and DASC is the same width or wider on weather, on finance and in the simulations. The theorem on long-run calibration of the adaptive update is also incorrect when the adaptive level is restricted to an interval, as it is in the experiments. Please do not rely on the manuscript, its tables or the files in `results/` for these claims. The code and saved results of the corrected evaluation are in https://github.com/jopoku16/dasc-controlled-evaluation.

Code, figures, and manuscript source for Drift-Aware Spectral Conformal Prediction for Non-Exchangeable Streaming Data.
